# [Pix] Como criar chave Pix?

Para cadastrar sua chave Pix no Avendre Pay, siga os passos abaixo:

  1. **Acesse sua conta no****Avendre Pay**.
  2. No menu principal, clique em Pix.
  3. Selecione a opção minhas chaves.
  4. Escolha o tipo de chave que deseja cadastrar (celular, e-mail, chave aleatória ou CPF/CNPJ).
  5. Confira os dados e finalize o cadastro, informando sua senha de confirmação.
