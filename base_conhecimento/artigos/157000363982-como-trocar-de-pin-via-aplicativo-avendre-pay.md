# Como Trocar de PIN via Aplicativo - Avendre Pay

### **Introdução**

A troca de senha e de PIN permite que usuários autenticados atualizem sua senha de acesso e PIN de forma segura, reforçando a proteção dos dados e das operações sensíveis realizadas dentro do Avendre Pay.

* * *

### **Troca de PIN**

Permite que usuários autenticados alterem seu PIN de segurança, utilizado para autorizar operações financeiras e ações sensíveis dentro do aplicativo. 

  


Abaixo vamos ver como **trocar de PIN****via Aplicativo.**

* * *

### **Passo a Passo**

1\. Acesse o menu na barra de navegação do aplicativo e selecione a opção “Alterar PIN” na seção **"Perfil"**. 

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008756127/original/4pIuzmVpm98EKkgHGbsGHZl3NquN6nr9Gg.png?1752581222)

  


2\. Informe seu PIN atual para continuar.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008756171/original/VZgN9EKC3C-6BJAwP4qn3i86lJINybrebQ.png?1752581259)

  


3\. Em seguida, escolha o método de autenticação de dois fatores: **SMS** ou**E-mail.**

**![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008756221/original/CF_VHJw6nI3jlQlL6diGVCtTN5BiZFgdkA.png?1752581306)**

4\. Insira o código de verificação enviado pelo canal escolhido. 

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008756253/original/3Qa2kBWKSSBVzgBnIkh-xfXfr0mIdVpWTg.png?1752581341)![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008756254/original/VXpjk1lZFfJbknp2Z8oyIgbI3yPtgpNW9A.png?1752581344)

  


5\. Após a validação do código, insira o novo PIN, seguindo os critérios de segurança definidos pelo sistema.![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008756301/original/U8stOH_UABcCdmLLeWYjC0LMnbVJYwrw9g.png?1752581401)

  


6\. Após a validação, o sistema exibirá uma mensagem confirmando se a alteração do PIN foi concluída com sucesso. ![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008756320/original/Uq87Qp0RY2i3lmpsyAZf6Xi8ooDxbh1oLA.png?1752581436)
