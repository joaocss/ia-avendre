# Minhas Chaves Pix via Web - Avendre Pay

**Introdução**

A funcionalidade Pix tem como objetivo viabilizar a realização, o recebimento e a gestão de transações Pix por usuários autenticados, de forma integrada, segura e com alta eficiência operacional.
    
    
    **Todos as transações Pix ficam visíveis na aba “Extratos”. Ao clicar na transação é possível acessar o comprovante da mesma.**

* * *

### **Minhas Chaves Pix**

Esta funcionalidade permite que você visualize, cadastre e exclua suas chaves Pix diretamente pelo aplicativo. O perfil de acesso contempla todos os usuários com conta ativa. 

  


Abaixo vamos ver como visualizar, cadastrar e excluir **suas chaves****Pix via Web.**

* * *

### **Passo a Passo**

1\. Acesse o menu **“Pix”** na lateral da plataforma web para entrar na **Área do Pix**. O sistema exibirá a l**ista de chaves Pix já cadastradas** na sua conta, organizadas por tipo:

  * CPF ou CNPJ

  * E-mail

  * Telefone

  * Chave aleatória




![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008727792/original/w6N2lXWBUl5vlAf07HlENaKVw-y4-siM5g.png?1752524434)

  


2\. Ao clicar no ícone de ação ao lado de uma chave cadastrada, você pode:

  * **Copiar a chave.**

  * **Excluir a chave** , confirmando a ação quando solicitado.




![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008727821/original/uZEd47AOyWnxdhs7mPzdPhX9XDrvPPZVOg.png?1752524476)

  


3\. Para criar uma nova chave, clique no botão **“Nova chave”**. O sistema exibirá as opções de tipo de chave disponíveis para seleção.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008727863/original/9V5SGEMbPHFjbvvdAOOM0N89RmNJTz08yg.png?1752524516)

4\. Após selecionar o tipo de chave, clique no botão **“Confirmar”** para prosseguir. 

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008727898/original/XwdZ85S7BHb_odHykvxmHRzUKzvgKsMr7A.png?1752524545)

  


5\. O sistema solicitará a autenticação por PIN para continuar.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008727917/original/GQludzDng04mT1ttYSX-6vOo6hcJiDr7Uw.png?1752524573)

  


6\. A chave será criada e adicionada à sua lista. O sistema exibirá uma mensagem de sucesso confirmando a operação.![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008727969/original/4UEXAc-bbbdF9GrFwr_OCtxvgoKr9dV4jQ.png?1752524636)
