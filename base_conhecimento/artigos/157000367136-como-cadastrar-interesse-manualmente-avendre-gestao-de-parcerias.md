# Como cadastrar interesse manualmente - Avendre Gestão de Parcerias

**ÍNDICE**

  * Introdução
  * Passo a passo para cadastrar um interesse manualmente
  * Vantagem



* * *

## **Introdução**

Em alguns casos, um parceiro pode enviar um interesse fora do sistema, por exemplo, via **WhatsApp**.  
Nessas situações, o incorporador pode registrar manualmente esse interesse dentro do **Gestor de Parcerias** , garantindo que o histórico fique completo no CV CRM.

##   


## **Passo a passo para cadastrar um interesse manualmente**

  1. **Acesse o menu**

     * No painel, clique em **Gestão de Parcerias**.  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157010710142/original/Rx0y9h8lTS6zW1tWygG5PxkEiyItKwe_dg.png?1755798842)  


  2. **Encontre o parceiro**

     * Use a barra de busca para localizar o parceiro desejado.

     * Clique em **Ver Parceiro**.  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157010710212/original/94pEBB3MdSauHEd0NcpaS7TifG1J-bOSww.png?1755798928)  


  3. **Cadastrar interesse**

     * Na lateral direita da tela, clique no botão **Cadastrar**.  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157010710280/original/wSiLylYAyxOGhrKh9CFFLYOkNfVpxSUDUw.png?1755799015)  


     * Preencha os dados do cliente enviados pelo parceiro:

       * **Empreendimento de interesse**

       * **Nome completo**

       * **E-mail**

       * **Telefone**

     * Caso queira, você também pode adicionar uma **mensagem complementar**.  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157010710328/original/wRCgl9i-SrAYqS8LvGtBx3QIvxSa1FiQzw.png?1755799058)  


  4. **Salvar**

     * Após preencher as informações, clique em **Cadastrar** para registrar o interesse.  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157010710393/original/gw5VlweGAFGRed8iKDLfNScJHZM2I6dxAw.png?1755799115)




##   


## **Vantagem**

Com esse recurso, mesmo que o parceiro não registre o interesse diretamente no sistema, você, incorporador, pode manter o **controle centralizado** , evitando perda de informações importantes.
