# Como Trocar de PIN via Web - Avendre Pay

## **Introdução**

A troca de senha e de PIN permite que usuários autenticados atualizem sua senha de acesso e PIN de forma segura, reforçando a proteção dos dados e das operações sensíveis realizadas dentro do Avendre Pay.

* * *

### **Troca de PIN**

Permite que usuários autenticados alterem seu PIN de segurança, utilizado para autorizar operações financeiras e ações sensíveis dentro do aplicativo. 

  


Abaixo vamos ver como **trocar de PIN****via Web.**

* * *

### **Passo a Passo**

1\. Acesse **“Minha conta”** na barra de navegação lateral da plataforma web e selecione a opção **“Alterar PIN”**. 

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008756357/original/VoNXrORfnicp9C_bDhebS03B1KgHqLY7xQ.png?1752581491)

  


2\. Em seguida, insira o código de verificação recebido por **SMS**.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008756381/original/MdXFAki2jORyQJohpv0n7ajWglgfrSZgjg.png?1752581571)

  


3\. Após validar o código, insira o novo PIN conforme os padrões de segurança exigidos pelo sistema.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008756418/original/8pPlA0E7Z7dMHoLGoaSk7FwpW5OSAP1LqQ.png?1752581615)

4\. Após a validação, o sistema exibirá uma mensagem confirmando se a alteração do PIN foi realizada com sucesso. 

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008756442/original/kijpvbEhMNeuQS52YzHphwT0gQRJJilYCw.png?1752581681)
