# Como Pagar com código Copia e Cola via Web - Avendre Pay

**Introdução**

A funcionalidade Pix tem como objetivo viabilizar a realização, o recebimento e a gestão de transações Pix por usuários autenticados, de forma integrada, segura e com alta eficiência operacional.
    
    
    **Todos as transações Pix ficam visíveis na aba “Extratos”. Ao clicar na transação é possível acessar o comprovante da mesma.**

* * *

### **Como Pagar com código Copia e Cola**

Essa funcionalidade permite que você realize um pagamento via Pix colando um código previamente copiado em outro ambiente (como e-mail, site ou aplicativo). É uma forma prática de pagar cobranças sem precisar escanear um QR Code. O perfil de acesso contempla todos os usuários com conta ativa. 

  


Abaixo vamos ver como **pagar com código Copia e Cola****via Web.**

* * *

### **Passo a Passo**

1\. Acesse o menu lateral da plataforma web, clique em **“Pix”** para entrar na **Área do Pix** e selecione o card **“Copia e Cola”**. 

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008722327/original/YNuxXrCsWXiP6a-Pqdfhp1p66ukG24kTaw.png?1752520144)

  


2\. O sistema exibirá um campo para colar o código Pix. Cole o código que você copiou previamente de outro ambiente, como site, app ou e-mail.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008722339/original/uDtlKDoIT4KnBRn0gmxv5xJ-bZTBBD2IqQ.png?1752520170)  


3\. Se o valor não estiver preenchido automaticamente, informe o valor da cobrança. 

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008722375/original/OsQlX_jE1fJTNzmZdFa9rOTsZubwjdOF3g.png?1752520200)  


4\. Após definir ou verificar o valor, o sistema exibirá os dados da cobrança. Revise as informações e clique em **“Confirmar”.**

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008722401/original/6W1i8EKJ5vjQCgngITxkG4t0ltmqlvOx6Q.png?1752520221)

  


5\. O sistema solicitará a autenticação por PIN para concluir a operação.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008722444/original/JbUVQx997Q0QrfVENaBsg_a9GntivILryA.png?1752520248)

6\. A transferência será processada e, em seguida, o sistema exibirá a **confirmação** junto com o **comprovante da transação.** Para compartilhar o comprovante, clique no botão **“Compartilhar”** no topo da tela. 

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008722467/original/VlPw0Ani7lux4NdrTS1GoxH9PdNHZOv4lQ.png?1752520276)
