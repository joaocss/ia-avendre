# [Múltiplas Contas] Não vejo a opção “Trocar Conta”. Por quê? - Avendre Pay

A opção é exibida apenas para usuários com mais de uma conta ativa.  
**Se você tem apenas uma conta vinculada ao seu CPF, o botão “Trocar Conta” não será exibido. Não é necessária nenhuma ação.**
