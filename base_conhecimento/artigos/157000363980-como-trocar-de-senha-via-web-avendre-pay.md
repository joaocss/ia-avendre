# Como Trocar de Senha via Web - Avendre Pay

### **Introdução**

A troca de senha e de PIN permite que usuários autenticados atualizem sua senha de acesso e PIN de forma segura, reforçando a proteção dos dados e das operações sensíveis realizadas dentro do Avendre Pay.

* * *

### **Troca de Senha**

Permite que usuários autenticados alterem sua senha atual por uma nova, mediante validação de identidade via código de autenticação.

  


Abaixo vamos ver como **trocar de senha via Web.**

* * *

### **Passo a Passo**

1\. Acesse**“Minha conta”** na barra de navegação lateral da plataforma web e selecione a opção **“Alterar minha senha”**. 

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008755958/original/Lbf9EM-WKJB6RkocevCqbB8ASNVYFkS4iw.png?1752580989)

  


2\. Em seguida, insira o código de verificação recebido por SMS.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008755980/original/qgzUTA_hSSG887YpFiygK14qtnGazoPtBA.png?1752581020)

  


3\. Após validar o código, insira a nova senha, seguindo os padrões de segurança exigidos pelo sistema.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008755997/original/njsglRINmQPAkhl7pcQoENj5V1Vha8wCYA.png?1752581054)

4\. Após a validação, o sistema exibirá uma mensagem confirmando se a alteração foi concluída com sucesso. 

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008756019/original/TRtpB1Mz2KgesP9231VFCy4LqLBOJSygcA.png?1752581083)
