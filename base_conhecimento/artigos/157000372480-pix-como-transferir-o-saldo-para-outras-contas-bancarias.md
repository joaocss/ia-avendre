# [Pix] Como transferir o saldo para outras contas bancárias?

Para isso, você conta com a funcionalidade **Pix** , que permite **transferir valores, pagar contas e cadastrar suas chaves para receber pagamentos**.

Para acessar, vá até a seção **Pix** no menu lateral do **Avendre Pay**.
