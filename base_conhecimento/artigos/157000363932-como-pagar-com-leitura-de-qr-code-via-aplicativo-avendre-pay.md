# Como Pagar com Leitura de QR Code via Aplicativo - Avendre Pay

**Introdução**

A funcionalidade Pix tem como objetivo viabilizar a realização, o recebimento e a gestão de transações Pix por usuários autenticados, de forma integrada, segura e com alta eficiência operacional.
    
    
    **Todos as transações Pix ficam visíveis na aba “Extratos”. Ao clicar na transação é possível acessar o comprovante da mesma.**

* * *

### **Como Pagar via QR Code**

Com essa funcionalidade, você pode realizar pagamentos via Pix de forma prática e segura, simplesmente apontando a câmera do celular para um QR Code gerado por outra pessoa ou instituição. O perfil de acesso contempla todos os usuários com conta ativa. 

  


Abaixo vamos ver como **pagar via QR Code via Aplicativo.**

* * *

### **Passo a Passo**

1\. Acesse o menu **“Pix”** na barra de navegação do aplicativo e selecione o card com a opção **“QR Code”**. 

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008720427/original/UuUuI4RAXPburRNP25Rgnbw8xZklRSzDEg.png?1752518749)2\. O sistema ativará a**câmera do seu dispositivo**. Aponte-a para o QR Code gerado por outra pessoa ou instituição para iniciar a leitura.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008720455/original/uSdVjad-3jfAVYvS5Iz_ok27U_8bHLv1tg.png?1752518786)

  


3\. Após a leitura bem-sucedida, confirme os dados da transferência. Opcionalmente, você pode:

  * **Alterar o valor** , clicando no ícone de edição.

  * **Agendar a transferência** , clicando no ícone de edição da data.  




    
    
    **Se optar por agendar, ao clicar em “Transferir”, você será direcionado para o fluxo de Agendamento.
    **

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008720572/original/mPbW37fkN-8tGVzVJBft0WwTfzpeq9HYPg.png?1752518845)

  


  * Adicionar uma **descrição.**
  * Marcar a opção para **salvar o contato** para transferências futuras. 
  * Após isso, clique em**“Transferir”.**



![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008720685/original/W79kQiazgLplHYbeM4xwq8SJbQ2TnGSJmA.png?1752518957)

  


4\. O sistema solicitará a autenticação por PIN para concluir o pagamento.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008720719/original/voffjoQ7BbQlXAtu5sjSHOKN3VYYOUNLgA.png?1752518981)

5\. A transferência será processada e, em seguida, o sistema exibirá uma tela com a**confirmação de sucesso** ou uma **mensagem de erro** , caso algo dê errado.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008720749/original/5s7nmTlZJHJUSzlpb2WYCP_KPzl51X8yOg.png?1752518997)

  


6\. Em caso **de sucesso, você poderá acessar o comprovante da transação** clicando em **“Ver comprovante”**. Para compartilhar, use o ícone de compartilhamento no topo da tela. 

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008720775/original/RFy1Skiwlq0_kFG_Ful9KLpX5hBM_x0f1w.png?1752519030)
