# [Login] Não estou conseguindo acessar minha conta ou não estou conseguindo fazer login.

Verifique se os dados de acesso foram digitados corretamente.

Login: utilize seu CPF.   
Senha: digite a senha cadastrada no sistema.

Caso não lembre sua senha, utilize a opção “minha senha” na tela de login para realizar a recuperação.
