# Como Administrar os Limites do Pix via Web - Avendre Pay

**Introdução**

A funcionalidade Pix tem como objetivo viabilizar a realização, o recebimento e a gestão de transações Pix por usuários autenticados, de forma integrada, segura e com alta eficiência operacional.
    
    
    **Todos as transações Pix ficam visíveis na aba “Extratos”. Ao clicar na transação é possível acessar o comprovante da mesma.**

* * *

### **Como Administrar os Limites do Pix**

Esta funcionalidade permite que você visualize seus limites Pix — diários e por transação — e solicite alterações desses valores diretamente pelo aplicativo. O perfil de acesso contempla todos os usuários com conta ativa. 

  


Abaixo vamos ver como **administrar os limites do Pix via Web.**

* * *

### **Passo a Passo**

1\. Acesse o menu **“Pix”** na lateral da plataforma web para entrar na **Área do Pix** e selecione o card **“Limites”**. 

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008754401/original/2iCuCzCjCTNaTi50Dl7SoGbYKQUecoYrjQ.png?1752578118)

  


2\. O sistema exibirá a tela com os Limites Pix, organizados por tipo:

  * **Diurno** : limite diário e por transação.

  * **Noturno** : limite diário e por transação.




![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008754429/original/Hx8WBZZ6PdSWadzmKjruFCWewOsz9CsezQ.png?1752578159)

  


3\. Você pode clicar em **“Alterar”** em qualquer um dos limites exibidos para modificá-lo. O sistema abrirá uma tela para que você defina o novo valor desejado.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008754441/original/oRgxjB8jFm3HsxUknmk-4we_yfzysxUh0Q.png?1752578208)  


4\. Após a autenticação, o sistema processará a solicitação e exibirá uma mensagem informando se a alteração foi concluída com sucesso ou se ocorreu algum erro. 

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008754458/original/IZcNtKDXbFCPsAweb35r-wL05U3m5wLemA.png?1752578248)![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008754462/original/zU8tth9upMcVosfTaG6c84qvPYhnzM54jQ.png?1752578251)
