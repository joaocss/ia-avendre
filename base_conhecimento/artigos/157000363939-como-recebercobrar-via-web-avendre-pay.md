# Como Receber/Cobrar via Web - Avendre Pay

**Introdução**

A funcionalidade Pix tem como objetivo viabilizar a realização, o recebimento e a gestão de transações Pix por usuários autenticados, de forma integrada, segura e com alta eficiência operacional.
    
    
    **Todos as transações Pix ficam visíveis na aba “Extratos”. Ao clicar na transação é possível acessar o comprovante da mesma.**

* * *

### **Como Receber/Cobrar via Pix**

Esta funcionalidade permite que você gere um QR Code ou um código no formato “copia e cola” para receber pagamentos via Pix. O perfil de acesso contempla todos os usuários com conta ativa. 

  


Abaixo vamos ver como **receber/cobrar via Web.**

* * *

### **Passo a Passo**

1\. Acesse o menu **“Pix”** na lateral da plataforma web para entrar na Área do Pix e selecione o card **“Receber”**.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008723300/original/ugOTnZ6fEZTw6-LYn3wd4fVhms2-hDpZrA.png?1752520988)

2\. Informe o valor da cobrança ou clique em **“Não especificar um valor”** para deixar o valor indefinido. 

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008723326/original/Zmfcg44PTAhrtVilJxJiFdYt_EHvngYoYg.png?1752521013)

  


3\. Após definir o valor (ou deixá-lo indefinido), o sistema exibirá os dados da cobrança. Preencha as informações:

  * **Selecione a chave Pix** em que deseja receber o valor.

  * **Adicione uma descrição** para a cobrança (opcional).




![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008723415/original/GaqdCvy7Ewp6UllLmtYPdK4zrFRoIcvb4g.png?1752521078)

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008723429/original/X8jXsn59Aa7SpJosY6FpiJ11VRV1H1DWWQ.png?1752521089)

  


4\. O sistema gerará dois tipos de código para recebimento. Você pode:

  * **Compartilhar o QR Code** , clicando no botão “Baixar QR Code”.

  * **Compartilhar o código Pix** , clicando no botão “Copiar código”.




![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008723479/original/H6pIFVd5PpeATIA1fh418Reg19JMFr1tsA.png?1752521122)
