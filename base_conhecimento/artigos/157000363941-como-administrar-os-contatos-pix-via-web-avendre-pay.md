# Como Administrar os Contatos Pix via Web - Avendre Pay

### **Introdução**

A funcionalidade Pix tem como objetivo viabilizar a realização, o recebimento e a gestão de transações Pix por usuários autenticados, de forma integrada, segura e com alta eficiência operacional.
    
    
    **Todos as transações Pix ficam visíveis na aba “Extratos”. Ao clicar na transação é possível acessar o comprovante da mesma.**

* * *

### **Como Administrar os Contatos Pix**

Esta funcionalidade permite que você exclua contatos salvos ou os utilize diretamente para iniciar uma nova transação. O perfil de acesso contempla todos os usuários com conta ativa. 

  


Abaixo vamos ver como **administrar contatos Pix via Web.**

* * *

### **Passo a Passo**

1\. Acesse o menu **“Pix”** na lateral da plataforma web para entrar na **Área do Pix** e selecione o card **“Transferir”**. 

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008724870/original/zkiD0wIiIAvaJ2j2fKlUx4Quh3GXOdmsnw.png?1752522130)  


2\. Na tela inicial de**“Transferir Pix”,** você pode:

  * **Adicionar um contato aos favoritos** , clicando no ícone correspondente.

  * **Remover um contato** , clicando no ícone de exclusão e confirmando a ação.
