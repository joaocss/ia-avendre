# Quanto custa para o corretor usar a Avendre? - Avendre Vitrine

A Avendre é totalmente gratuita para corretores de imóveis devidamente credenciados ao CRECI da sua região. Não há mensalidades, taxas ou qualquer tipo de cobrança para acessar as informações dos empreendimentos disponíveis na plataforma. O corretor pode utilizar a Avendre sem custos e aproveitar todas as vantagens da ferramenta.
