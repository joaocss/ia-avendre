# Como Administrar os Limites do Pix via Aplicativo - Avendre Pay

**Introdução**

A funcionalidade Pix tem como objetivo viabilizar a realização, o recebimento e a gestão de transações Pix por usuários autenticados, de forma integrada, segura e com alta eficiência operacional.
    
    
    **Todos as transações Pix ficam visíveis na aba “Extratos”. Ao clicar na transação é possível acessar o comprovante da mesma.**

* * *

### **Como Administrar os Limites do Pix**

Esta funcionalidade permite que você visualize seus limites Pix — diários e por transação — e solicite alterações desses valores diretamente pelo aplicativo. O perfil de acesso contempla todos os usuários com conta ativa. 

  


Abaixo vamos ver como fazer **administrar os limites do Pix via Aplicativo.**

* * *

### **Passo a Passo**

1\. Acesse o menu **“Pix”** na barra de navegação do aplicativo e selecione o card **“Limites”**. 

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008754231/original/GMr_gCg7SFos3ghnYAaNbAp4dVQcZlYcrw.png?1752577807)2\. O sistema exibirá a tela de Limites Pix, com os valores organizados por tipo:

  * **Diurno** : limite diário e por transação.

  * **Noturno** : limite diário e por transação.




![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008754253/original/_sl4PnD0P3pHqi2j3EyPZE25shDeff5VAA.png?1752577865)

  


3\. Você pode clicar em qualquer um dos limites exibidos para alterá-lo. O sistema abrirá uma tela para que você defina o novo valor desejado. 

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008754286/original/g9LLTw2nUXPZMuZEJqTNiz8gEniMnN5y1g.png?1752577917)

  


4\. Após preencher os dados com o novo valor, confirme a solicitação. O sistema solicitará a autenticação por PIN para prosseguir.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008754324/original/DPqHYmr_l8yeinzWozM4qf8VUrID_lRKBg.png?1752577977)

  


5\. Após a autenticação, o sistema processará a solicitação e exibirá uma mensagem informando se a alteração foi realizada com sucesso ou se ocorreu algum erro. 

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008754368/original/jBJiAYvDZ5ur6hpMvHkjd97u0SYiEwk3zA.png?1752578022)
