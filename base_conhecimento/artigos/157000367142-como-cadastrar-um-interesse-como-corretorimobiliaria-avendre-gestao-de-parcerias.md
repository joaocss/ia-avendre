# Como cadastrar um interesse como Corretor/Imobiliária - Avendre Gestão de Parcerias

**ÍNDICE**

  * Introdução
  * Passo a passo para cadastrar um interesse
  * Benefício



* * *

## **Introdução**

Ao acessar como **Corretor ou Imobiliária** na Avendre, você pode cadastrar interesses de clientes de forma rápida e prática. Esse recurso é útil quando um cliente demonstra interesse em um empreendimento e unidade específica, permitindo que você envie essa informação diretamente para o gerente de parceria.

  


## **Passo a passo para cadastrar um interesse**

  1. **Acesse a vitrine**

     * Na tela inicial temos a **Vitrine**.   
  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157010716307/original/O4HMT7Pmtmr3eBnP_R-rJgeNZd0l2vkSRA.png?1755804256)  


  2. **Busque o empreendimento**

     * Utilize a barra de pesquisa para localizar o empreendimento desejado.   
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157010716323/original/iYnt0X1-hJ3WM805npflmzVVPxD4ZOIQmw.png?1755804279)   


  3. **Selecione a unidade**

     * Clique sobre o empreendimento.   
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157010716368/original/44c3aupZSAXhnAa64DOY0OWY3RDPAabBZw.png?1755804315)   


     * Em seguida, procure a unidade que o cliente demonstrou interesse.   
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157010716393/original/PYhDgmzblI0Ie_D0n7NJ2tZZ49i43Mq2Iw.png?1755804343)   


  4. **Enviar interesse**

     * Clique em **Enviar Interesse**.   
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157010716398/original/lcMrjA7tUZx1PGbza6CtH1VepFJYk6Uofw.png?1755804358)   


     * Selecione o **Gerente de Parceria**.   
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157010716487/original/LxoeNcF3Mc5A0F43o7QGyX8flK8gJ3D-4Q.png?1755804456)   


     * (Opcional) Adicione os dados do cliente:

       * Nome completo

       * E-mail

       * Telefone  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157010716564/original/W-y9l7xU6dRHyprUh3KgWl45ZlYmDm-tBA.png?1755804479)

       * Inclua uma **mensagem personalizada** para o gerente de parceria.   
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157010716678/original/pS87dcvko-yrJU6fBlsgvO27zJlOi57HYA.png?1755804506)

  5. **Finalizar**

     * Após preencher as informações, confirme o envio para registrar o interesse no sistema.   
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157010716693/original/-du5cpaWpN2P9Inlv3LG-ijbJS_ahtNcQQ.png?1755804524)

## **Benefício**

Esse processo garante que o gerente de parceria receba todas as informações organizadas, facilitando o atendimento e o acompanhamento da negociação.
