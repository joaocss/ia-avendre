# Como Selecionar Conta após Login via Web - Avendre Pay

### **Introdução**

Esta funcionalidade permite que beneficiários com**múltiplas contas vinculadas ao mesmo CPF** escolham, de forma prática, **qual conta desejam acessar logo após a autenticação.**  


  


Destina-se a usuários autenticados com mais de uma conta ativa, garantindo uma experiência fluida sem necessidade de login adicional para alternar entre perfis.

* * *

### **Seleção de Conta após Login**

Após a autenticação ser concluída com sucesso, se o sistema identificar que seu CPF está vinculado a mais de uma conta, você será direcionado para uma tela de seleção. Nela, poderá escolher qual das contas vinculadas deseja acessar, recurso disponível exclusivamente para usuários com múltiplas contas ativas. 

  


Abaixo vamos ver como **selecionar uma conta após login via Web.**

* * *

### **Passo a Passo**

1\. Abra o aplicativo Avendre Pay.

2\. Realize o login com suas credenciais.

3\. Após a autenticação bem-sucedida, se houver mais de uma conta vinculada ao seu CPF, o sistema exibirá uma tela com a lista de contas disponíveis. Selecione a conta que deseja acessar e clique em **“Confirmar”**.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008759783/original/NYCsKf2pWO1b93M-fE1_0TEv2BMHbJkbDw.png?1752585403)

  


4\. Após confirmar a conta selecionada, você será direcionado automaticamente para a tela inicial do app (Home).

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/157008759812/original/Oj86qwP9gCM3tap4K-a1PFBXlyTWhm4WXg.png?1752585426)
    
    
    **Observação: Este fluxo acontece logo após o Login e antes do acesso à Home. Para saber como realizar a troca de conta em sessão,[clique aqui](<https://avendrepaycom.freshdesk.com/pt-BR/support/solutions/articles/157000364037>).**
