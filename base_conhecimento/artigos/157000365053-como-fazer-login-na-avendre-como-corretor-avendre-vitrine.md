# Como Fazer Login na Avendre como Corretor - Avendre Vitrine

### Passo a passo para fazer login (Corretor)

1. **Acesse o site oficial:** abra o navegador e digite **www.avendre.com.br**, pressione Enter.
2. **Localize a area de login:** quando o site carregar, clique em **"Corretor"**.
3. **Insira suas credenciais:**
   - **E-mail:** o endereco cadastrado no Avendre.
   - **Senha:** sua senha de acesso.
   - Dica: verifique se o **Caps Lock** esta desativado.
4. **Conclua o login:** clique em **"Acessar"**.

### Problemas para acessar?

- Confira se digitou corretamente e-mail e senha.
- Verifique se a conexao esta estavel.
- Para redefinir, clique em **"Esqueci minha senha"** e siga as instrucoes.
